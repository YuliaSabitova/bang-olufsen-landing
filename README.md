Project Description
This project is a landing page for the Bang & Olufsen online store. The website is designed to showcase and sell audio products, including portable speakers, headphones, and smart home systems.
Main sections of the page:
•	Main Page Header– with a promotional slogan and navigation menu.
•	Product Catalog – images and descriptions of recommended products.
•	Product Categories – segmented selection of audio products.
•	About Us – the brand’s history and its classic models.
•	Contact – feedback form and contact details.
Technologies Used
•	HTML5 – structure of the web page.
•	SCSS (Sass) – for styling, simplifying style management.
•	Responsive Design – adaptive layout for correct display on different devices.
•	BEM (Block Element Modifier) – a methodology for organizing CSS code, improving readability and scalability.
•	CSS Flexbox & Grid – used for flexible and efficient element positioning.
•	CSS Transformations & Animations – for smooth visual effects and animations.
